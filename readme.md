Dataset format: labelme format (without mask files, only including jpg images and corresponding json files)

Number of images (number of jpg files): 4000

Number of annotations (json file count): 4000

Label count: 6

Annotation category names: ["scratch", "tire flat", "crack", "lamp broken", "dent", "glass shatter"]

Annotation rules: Draw polygons around the categories.
